# Agent Note: 保守的模型信息自动填充

Status: proposed

[English](2026-11-05-model-metadata-autofill.md) | 中文

## Problem

新模型 ID 可能先于内置目录出现，提供商列表声明的信息也可能在发现流程中丢失。旧自定义模型并未记录每个字段是推断值还是手动选择，静默转换会覆盖用户设置。

## Proposal

增加经来源核实的 GPT Image 2.6 精确目录项，并在添加新模型时校验部分 Gemini/OpenRouter 结构化信息。未公布的限制与价格保持未知。经维护核实的目录值优先于经过校验的提供商结构化回退值，后续手动覆盖优先于目录。保留目录精确匹配优先、其次规范化回退的现有规则，不根据陌生模型名称猜测能力或限制。

在模型编辑器提供经明确确认的“使用目录默认配置”。整体重置能力、输入输出模态、Token 限制、流式、参数支持、推理和价格，之后跟随目录。保留身份、API ID、名称、描述、分组、接口、启用/隐藏/弃用状态、备注和引用。目录未知值保持缺失，不能变成零价或免费。无匹配或失败不修改数据。确认前不动旧配置，恢复后仍可手动覆盖。

本阶段不增加持久化提供商快照，不自动迁移旧自定义行。提供商发现值仅作为普通配置初始化新添加的自定义模型，不另设提供商来源持久层，也不刷新旧行。已有目录模型继续继承当前基准。Gemini 提供经校验的输入输出限制；OpenRouter 提供声明的模态、由声明推导的能力和 Token 限制。不导入提供商价格。界面说明来源和恢复影响。不包含发布或修改目录更新渠道。

## Alternatives considered

- 从 2.5 或 ID 模式猜测 2.6 信息会宣称不支持的能力。
- 静默关联旧自定义行与预设会改变原先为空、未选择的字段。
- 旧自定义行逐字段恢复需要新增来源记录，本阶段改为明确说明影响的整体恢复。
- 放宽远程新旧检查可能让旧上游目录覆盖新版分支目录。

## Acceptance criteria

- AC1 — 2.6 精确型号具有已核实的图片能力，不编造限制 (verification: unit)
- AC2 — 已校验的提供商字段贯穿发现和新模型添加，不覆盖旧用户行 (verification: unit | renderer)
- AC3 — 恢复需确认，显示目录来源和未知字段，保留未选的身份、接口和状态，之后跟随目录 (verification: renderer | unit)
- AC4 — 失败、目录无匹配、取消与切换模型不改变旧配置；恢复后的手动编辑优先于目录 (verification: renderer | unit)

## Risks

目录描述模型能力，不代表账户权限或每个网关的实际行为。提供商派生的自定义配置不会持续刷新。整体恢复会替换提示中列出的手动配置。单元测试不代表真实付费提供商或 Windows 打包验收通过。
